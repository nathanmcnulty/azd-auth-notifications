# Product scope

Deploying administrators select email and/or personal Teams notifications for affected end users. Optional administrator notifications have independent channel selection and recipient IDs. Azure Communication Services is a future option for both audiences.

Use supported Entra audit data, managed identity, durable per-recipient state, explicit pilot scope, and scoped sender permissions. Sign-in risk, location/device baselines, and remediation are outside this milestone.

Keep readiness claims tied to evidence: local tests, infrastructure validation, deployed execution, provider acceptance, and observed recipient delivery are distinct.
